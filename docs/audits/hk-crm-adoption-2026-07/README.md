# hk-crm design-baseline adoption — audit findings (2026-07)

The raw 360° consistency audit that drove the hk-crm adoption of the design-baseline
(the `IMPLEMENTATION.md` Steps 0–6 migration, shipped 2026-07). Preserved here as the
engagement record; the generalized methodology these produced was promoted into the
baseline (`docs/CHOOSING-A-SURFACE.md`, `docs/PLACEMENT.md`, `docs/STACK.md`,
`docs/ADOPTION.md` — see ADR-0002).

Self-contained HTML — open in any browser, works offline. Cross-links between the pages
only resolve in the original engagement bundle.

| File | What it is |
|---|---|
| `360 Audit.html` | Seven-dimension scorecard (principles, tokens, components, UX consistency, a11y, code enforcement, governance), top-3 risks, token inventory, before/after fixes, roadmap. |
| `Flow Consistency Audit.html` | The "stitched vs smooth" diagnosis — two navigation conventions, live side-by-side demos, the surface ladder, canonical flow recipes. |
| `UX Coverage Audit.html` | CRM process × archetype coverage matrix, registry lag, gap proposals filtered through the Rule of 2. |
